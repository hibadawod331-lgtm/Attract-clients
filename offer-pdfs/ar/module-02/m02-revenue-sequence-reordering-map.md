## الهدف

ورقة العمل هذه تساعدك تضعين أنشطة جذب العميلات بالترتيب المطلوب لتحويل الخبرة والمحتوى إلى محادثات مدفوعة مع عميلات. ستقررين ما يجب توضيحه، أو بناؤه، أو ربطه قبل أن تشتغل المرحلة التالية، حتى تتوقفي عن صنع نشاط ليس له مكان يقود إليه.

في النهاية، سيكون عندك ترتيب بناء واحد متفق عليه للمراحل الست، وقائمة بالأنشطة التي يجب إيقافها مؤقتا أو نقلها، وتسليم واضح من كل مرحلة إلى التي بعدها.

## التعليمات

خصصي 30 إلى 45 دقيقة خلال الجلسة.

- اكتبي أنشطة البيع والتسويق التي تعملينها حاليا أو تستعدين لعملها. استخدمي أنشطة محددة، وليس أهدافا عامة. مثلا: «نشر ريلز تعليمية» بدل «كبر البراند تبعي».
- ضعي كل نشاط في مكانه من التسلسل ذي المراحل الست.
- قارني ترتيبك الحالي بالترتيب المطلوب.
- حددي الأنشطة التي تحدث مبكرا جدا، أو متأخرا جدا، أو من دون خطوة ضرورية قبلها.
- استخدمي أسئلة بوابات المراحل لتتأكدي أن كل مرحلة جاهزة لتسلم للتي بعدها.
- اختمي باختيار أول مرحلة ستعيدين بناءها والأنشطة التي يجب إيقافها مؤقتا حتى يصبح التسلسل جاهزا.

هذه ليست جرد محتوى أو مراجعة أداء. الهدف إعادة ترتيب الشغل، وليس جمع كل أصل أو قياس كل نتيجة.

## 3. ضعي كل نشاط في ترتيب المراحل الست

ترتيب البناء المطلوب هو:

- **1. التموضع:** وضحي الجمهور، والمشكلة، ووجهة النظر.
- **2. العرض:** حولي الخبرة إلى حل مدفوع محدد.
- **3. الثقة:** أعطي الناس أسبابا ليصدقوا أن المشكلة مفهومة وأن الحل موثوق.
- **4. الجذب:** استخدمي محتوى ودعوات مرتبطة لتقربي الناس المناسبين نحو محادثة.
- **5. الإغلاق:** قودي محادثة مع شخص مناسب نحو قرار شراء واضح.
- **6. الدخل المتكرر:** اربطي النشر، والدعوة، والمتابعة، والتقديم، والتحسين في إيقاع مستدام.

لكل نشاط من القسم 2، حددي مرحلته المطلوبة. ثم سجلي أين يقع حاليا في البزنس تبعك.

| النشاط | رقم المرحلة المطلوبة | المرحلة المطلوبة | أين يحدث حاليا | حالة الترتيب |
| مثال: أشرح خدمتي في مكالمة بيع | 2 | العرض | 5، خلال الإغلاق | متأخر جدا / غير واضح |

اختاري حالة واحدة لكل نشاط:

- **بالترتيب:** يحدث بعد المرحلة التي يعتمد عليها.
- **مبكر جدا:** يطلب من الناس أن يتصرفوا قبل أن يكون الأساس الضروري موجودا.
- **متأخر جدا:** يستخدم لتعويض مرحلة سابقة غير واضحة.
- **مفكك:** موجود، لكن ليس له تسليم محدد إلى المرحلة التالية.
- **لم يبن بعد:** التسلسل يحتاج هذا النشاط قبل أن تشتغل الخطوة التالية.

## 5. افحصي بوابة كل مرحلة

المرحلة جاهزة للتسليم فقط عندما يكون عند المرحلة التالية شيء واضح تشتغل عليه. جاوبي على كل سؤال بـ: نعم، أو ليس بعد، أو يحتاج مراجعة. لكل جواب غير «نعم»، اكتبي القرار المطلوب.

| بوابة المرحلة | جاهزة؟ | القرار أو المراجعة المطلوبة |
| 1 ← 2: هل أقدر أقول من أساعد، والمشكلة التي أعالجها، ووجهة النظر التي أقدمها بوضوح كاف لتشكيل عرض؟ | | |
| 2 ← 3: هل يوجد عرض مدفوع واحد محدد يقدر نشاط بناء الثقة يجعله أكثر مصداقية؟ | | |
| 3 ← 4: هل عندي سبب موثوق يجعل الشخص المناسب ينتبه ويكمل المحادثة؟ | | |
| 4 ← 5: هل نشاط الجذب عندي فيه دعوة طبيعية وغير باردة إلى محادثة خاصة؟ | | |
| 5 ← 6: هل عملية الإغلاق تنتهي بقرار وخطوة تالية واضحين بدل تبادل مفتوح بلا نهاية؟ | | |
| 6 ← 1: هل يقدر هذا النظام الأسبوعي يتكرر من دون الاعتماد على النشر المستمر، أو الاستعجال الشخصي، أو أداء الخوارزمية؟ | | |

## الإكمال

يجب أن يكون عندك الآن:

- ترتيب واضح للمراحل الست لشغل جذب العميلات
- كل نشاط حالي محدد في مرحلته الصحيحة
- أول تسليم مكسور محدد
- أنشطة لتنقليها، أو توقفيها مؤقتا، أو تربطيها
- أول مرحلة محددة لإعادة البناء وشرط جاهزية للتقدم

أحضري هذه الخريطة إلى جلسة العمل التالية. استخدميها لبناء أول مرحلة غير محلولة بالترتيب، بدل صنع محتوى أو نشاط بيع أكثر فوق أساس غير واضح.
