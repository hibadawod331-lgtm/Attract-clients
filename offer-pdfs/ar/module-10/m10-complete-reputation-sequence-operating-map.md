## الهدف

ورقة العمل هذه تساعدك تربطين تموضعك، وعرضك، والثقة، والجذب، ومحادثات البيع، والإغلاق، والمتابعة في طريق عميلات حي واحد. بدل معاملة كل نشاط كشيء منفصل، ستحددين ما الذي ينقل الشخص من مرحلة إلى التالية، وماذا يجب أن يشوف أو يستلم، وماذا ستعملين عندما يكون جاهزا ليكمل.

في النهاية، سيكون عندك خريطة تشغيل عملية واحدة لتحويل خبرتك ومحتواك الموجود إلى محادثات حقيقية مع عميلات ودخل متكرر، من دون بيع بارد أو اعتماد على أداء الخوارزمية.

## التعليمات

خصصي 60 إلى 75 دقيقة لإكمالها.

- اختاري عرضا واحدا ومشكلة جمهور واحدة لترسميها. لا تبني طريقا لعدة عروض مرة واحدة.
- أكملي خريطة المراحل الست بالترتيب. كل مرحلة يجب أن تجهز المشترية للمرحلة التالية.
- لكل مرحلة، حددي: إشارة البداية عند المشترية، وفعلك، والأصل أو المحادثة المستخدمة، والشرط الذي يظهر أن المشترية جاهزة للتقدم، وماذا يحدث إذا لم تكن جاهزة بعد.
- اكتبي الكلمات الفعلية التي ستستخدمينها قدر الإمكان. تجنبي مدخلات مبهمة مثل «انشري أكتر» أو «ابني ثقة» أو «تابعي».
- استخدمي فحص التسليم لتجدي الروابط الناقصة بين المراحل.
- اختمي بكتابة طريقك الحي في تسلسل قصير واحد تقدرين تشرحينه وتطبقينه فورا.

هذا ليس تقويم محتوى أو سجل تتبع لخط العميلات. أنتِ تصممين كيف تشتغل الأجزاء مع بعض.

## 2. ابني خريطة تشغيل المراحل الست

أكملي كل سطر بالترتيب. عمود «شرط الجاهزية للتقدم» مهم بشكل خاص: يمنعك من دفع أحد إلى المرحلة التالية قبل أن يوجد الفهم أو النية الضرورية.

| المرحلة | إشارة البداية عند المشترية | فعلك المحدد | الأصل أو الرسالة أو المحادثة المستخدمة | شرط الجاهزية للتقدم | إذا لم تكن جاهزة |
| 1. التموضع | ما الذي يجب أن يجعل الشخص المناسب يتعرف أن شغلك مرتبط به؟ | كيف ستذكرين من تساعدين، وما المشكلة التي تعالجينها، ومنهجك؟ | جملة البروفايل، أو منشور مثبت، أو تعريف، أو نقطة دخول أخرى | الشخص يقدر يحدد أن المشكلة واتجاه الحل مرتبطان به. الدليل: | ما الذي سيبقي العلاقة مفتوحة من دون صنع ضغط؟ |
| | | | | | |
| 2. العرض | أي مشكلة، أو رغبة، أو سؤال يربط الشخص بهذا العرض تحديدا؟ | كيف ستربطين المشكلة بعرضك من دون تقديم كل خدمة ممكنة؟ | شرح العرض أو الدعوة | الشخص يفهم ما المشمول، ولمن، والنتيجة المقصودة، والخطوة التالية. الدليل: | أي توضيح أو مصدر سيساعده يفهم العرض لاحقا؟ |
| | | | | | |
| 3. الثقة | أي شك ممكن يمنع الشخص من تصديق أنك تقدرين تساعدين؟ | ماذا ستظهرين، أو تشرحين، أو تعرضين لتقللي هذا الشك؟ | دليل، أو مثال، أو تطبيق عملي، أو رأي عميلة، أو شرح تشخيصي | الشخص يقدر يشوف رابطا موثوقا بين خبرتك، ومنهجك، ومشكلته. الدليل: | أي دليل بناء ثقة مناسب لمشاركته بعد ذلك؟ |
| | | | | | |
| 4. الجذب | أي إشارة تظهر أن الشخص يفكر فعليا في المشكلة؟ | ماذا ستنشرين أو تقولين يجعل الشخص المناسب يريد أن يرد؟ | زاوية محتوى، أو قصة، أو سؤال، أو دعوة للتفاعل | الشخص يرد، أو يسأل سؤالا مرتبطا، أو يسمي المشكلة، أو يقبل دعوة خاصة. الدليل: | ماذا يجب أن يستلم أو يشوف قبل دعوة أخرى؟ |
| | | | | | |
| 5. المحادثة والإغلاق | ما الذي يجعل هذا الشخص مناسبا لمحادثة بيع الآن؟ | أي أسئلة ستسألين، وكيف ستقدمين العرض إذا كان هناك تناسب؟ | تدفق المحادثة، والدعوة، وتقديم العرض، وسؤال القرار | الشخص عنده معلومات كافية ليتخذ قرارا واضحا: نعم، أو لا، أو ليس الآن. نقطة القرار: | ما الخطوة التالية المتفق عليها ومتى ستأخذينها؟ |
| | | | | | |
| 6. المتابعة والدخل المتكرر | ماذا يحدث بعد قرار، أو تأجيل، أو شراء، أو تعاقد مكتمل؟ | كيف ستحافظين على العلاقة، وتوفين بالالتزام التالي، وتصنعين طريق استمرار؟ | رسالة متابعة، أو خطوة استقبال، أو نقطة فحص للتقديم، أو تجديد، أو توصية، أو دعوة للاستمرار | العميلة أو العميلة المحتملة عندها فعل تالي واضح، والعلاقة لا تعتمد على تذكرك اليدوي. الدليل: | أي تاريخ، أو محفز، أو حدث محدد يرجع هذا الشخص إلى الطريق؟ |

## الإكمال

يجب أن يكون عندك الآن:

- عرض واحد ومشكلة جمهور واحدة مختارين للتطبيق
- طريق كامل من ست مراحل من التموضع إلى الدخل المتكرر
- فعل، وأصل، وإشارة مشترية محددة لكل مرحلة
- تسليمات واضحة تظهر متى يتقدم الشخص
- طريق للناس المهتمين لكن غير الجاهزين
- أضعف رابط واحد وإصلاح محدد له
- قواعد تشغيل للمحادثات، والقرارات، والمتابعة، والاستمرار

استخدمي هذه الخريطة في جلسة التطبيق المباشرة لبناء أو مراجعة الرسائل الفعلية، ونقطة الدخول في البروفايل، والدعوة، وتدفق المحادثة، وفعل المتابعة. خطوتك التالية أن تركبي أضعف تسليم أولا، ثم تشغلي الطريق الكامل مع ناس حقيقيين وتراقبي أين تتوقف الحركة.
