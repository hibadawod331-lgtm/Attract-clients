## الهدف

ورقة العمل هذه تساعدك تراجعين ماذا حدث في خط العميلات عندك وتحددين عنق الزجاجة التالي الذي يجب إصلاحه. ستقارنين الاستفسارات الحقيقية، والمحادثات النشطة، والقرارات، والعميلات، والأنماط المتكررة حتى يكون تعديلك التالي مبنيا على أدلة، وليس على لايكات، أو تخمينات، أو ضغط لصنع محتوى أكثر.

## التعليمات

خصصي 30 إلى 45 دقيقة في نهاية كل فترة مراجعة. استخدمي سجلات آخر أسبوع أو أسبوعين، أو فترة ثابتة أخرى تعطيك نشاطا كافيا للمراجعة.

- اجمعي ملاحظات الجلسات، وسجلات المحادثات، وملاحظات القرارات، وسجلات العميلات، وسجلات المتابعة.
- سجلي الأرقام كما حدثت بالضبط. لا تقدري من الذاكرة.
- راجعي أين دخل الناس خط العميلات، وأين تقدموا، وأين توقفوا.
- ابحثي عن أبكر نقطة تباطأت فيها الحركة أو توقفت. هذه غالبا عنق الزجاجة الذي يجب معالجته أولا.
- اختاري تعديلا واحدا لفترة المراجعة التالية. لا تغيري تموضعك، وعرضك، ومحتواك، وعملية المحادثة، والمتابعة كلها مرة واحدة.
- سجلي التعديل، والدليل خلفه، والنتيجة التي ستراقبينها.

## 3. افصلي مشاكل الكمية عن مشاكل التحويل

أكملي كل سطر باستخدام أدلة محددة من فترة المراجعة هذه.

| السؤال | الدليل من فترة المراجعة هذه |
| هل أصبح عدد كاف من الناس المناسبين استفسارات حقيقية؟ | |
| هل أصبحت الاستفسارات الحقيقية محادثات نشطة؟ | |
| هل تقدمت المحادثات النشطة إلى عرض أو دعوة واضحة؟ | |
| هل حصل الناس على وضوح كاف ليتخذوا قرارا؟ | |
| هل أصبحت القرارات عميلات جدد؟ | |
| هل حصلت العميلات على خطوة تالية واضحة نحو الاستمرار أو شغل متكرر؟ | |
| هل حدثت المتابعة عندما كانت مستحقة؟ | |

الآن اختاري الجملة التي تصف المشكلة الحالية بأفضل شكل:

[] **استفسارات حقيقية غير كافية:** المشكلة الأساسية أن ناسا مرتبطين قليلين جدا يدخلون خط العميلات.
[] **تقدم المحادثات:** الناس المناسبون يدخلون، لكن المحادثات لا تتحرك نحو خطوة تالية واضحة.
[] **وضوح العرض أو القرار:** الناس يصلون إلى العرض، لكن يترددون، أو يسألون نفس الأسئلة، أو لا يقررون.
[] **تنفيذ المتابعة:** الفرص تبقى مفتوحة لأن المتابعة متأخرة، أو ناقصة، أو غير واضحة.
[] **تدفق العميلات أو الاستمرار:** العميلات يأتين، لكن التقديم، أو التجديد، أو الفرص المتكررة لا تتقدم بشكل مقصود.
[] **لا يوجد عنق زجاجة واضح بعد:** فترة المراجعة صغيرة جدا أو السجلات غير مكتملة.

## الإكمال

بإكمال ورقة العمل هذه، يجب أن يكون عندك:

- لقطة واضحة للاستفسارات الحقيقية، والمحادثات النشطة، والقرارات، والعميلات، وفرص الاستمرار.
- النقطة المحددة التي تتباطأ فيها الحركة في خط العميلات أو تتوقف.
- أدلة تفرق بين قلة الاستفسارات الحقيقية ومشكلة في التحويل، أو المتابعة، أو الاستمرار.
- نمط متكرر واحد يستحق المعالجة.
- تعديل مركز واحد وإشارات محددة للحكم على أثره.

استخدمي التعديل المختار في أنشطة تدفق العميلات الأسبوعية، ثم أحضري السجل المكتمل إلى مراجعة الإرشاد التالية. أبقي التغيير إذا تحسنت الأدلة، وعدليه إذا تحسنت الحركة جزئيا فقط، أو احذفيه إذا بقي عنق الزجاجة بلا تغيير.
