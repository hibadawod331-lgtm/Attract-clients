## الهدف

استخدمي ورقة العمل هذه خلال محادثة بيع مع عميلة محتملة لتوجهيها من وضعها الحالي إلى قرار شراء واضح. تساعدك تشخصين الفجوة بين مكانها الآن والنتيجة التي تريدها، وتوضحين ثمن ترك هذه الفجوة من دون حل، وتؤكدين التناسب، وتقدمين عرضك من دون تحويل المحادثة إلى استشارة غير مدفوعة.

في النهاية، يجب أن تعرفي هل العميلة المحتملة مناسبة، وماذا تحتاج أكثر، وكيف يعالج عرضك هذه الحاجة، وأي قرار أو خطوة تالية مناسبة.

## التعليمات

- أكملي قسم «قبل المكالمة» باستخدام المعلومات التي شاركتها العميلة المحتملة أصلا. لا تفترضي تفاصيل لم تتأكدي منها.
- خلال المحادثة، اتبعي الترتيب التالي. اسألي الأسئلة بكلماتك الخاصة، ثم سجلي لغة العميلة المحتملة المحددة.
- ابقي مع المشكلة الحالية وقتا كافيا لتفهمي أثرها. لا تقفزي إلى شرح عرضك مبكرا جدا.
- استخدمي «فحص التناسب» قبل تقديم العرض. أوصي بعرضك فقط إذا كان وضع العميلة المحتملة يطابق الشغل الذي صمم ليحله.
- قدمي العرض بربطه بالمشكلة والنتيجة المرغوبة التي ذكرتها العميلة المحتملة. لا تعيدي تصميم عرضك مباشرة أثناء المكالمة ولا تضيفي استشارة غير مدفوعة.
- استخدمي «طريق القرار» لتحددي هل العميلة المحتملة جاهزة للشراء، أو تحتاج توضيحا محددا، أو غير مناسبة.

## 3. ثمن المشكلة: ماذا يصنع هذا الوضع؟

لا تستخدمي هذا القسم للضغط على العميلة المحتملة. استخدميه لتجعلي الأثر ظاهرا.

اسألي فقط الأسئلة التي تناسب ما شاركته أصلا.

### الأثر العملي

**لأن هذه المشكلة مستمرة، ماذا تكلفها؟**

[] فرص ضائعة
[] وقت غير مدفوع في الصنع أو الشرح
[] نتائج غير متوقعة
[] تخفيض السعر أو تقديم أكثر من المتفق عليه
[] الاعتماد على التوصيات أو الصدفة
[] طاقة ضائعة كان ممكن تذهب للشغل الصحيح
[] تأخير إطلاق، أو توسع، أو انتقال
[] غير ذلك: _______________

## 5. فحص التناسب: هل يقدر عرضك يحل المشكلة الصحيحة؟

أكملي هذا قبل تقديم العرض. التناسب القوي يتطلب أكثر من الرغبة في نتيجة أفضل.

| سؤال التناسب | دليل من المحادثة |
| هل عندها المادة الخام التي صمم عرضي ليشتغل عليها؟ | |
| هل تحديها الأساسي هو الذي يحله عرضي فعلا؟ | |
| هل هي مستعدة للبناء مما عندها بدل البدء من جديد؟ | |
| هل تريد عملية مباشرة وتطبيقية بدل شيء مسجل مسبقا؟ | |
| هل هي مستعدة لعمل الشغل بين الجلسات؟ | |
| هل تقدر تشارك طوال مدة التعاقد كاملة؟ | |
| هل تفهم أن الشغل يصنع فرصا لكنه لا يقدر يضمن أي نتيجة محددة؟ | |

### قرار التناسب

[] **تناسب قوي:** العرض يعالج المشكلة مباشرة، والعميلة المحتملة جاهزة للمشاركة.
[] **تناسب ممكن مع توضيح:** الحاجة مرتبطة، لكن قلقا واحدا يجب معالجته قبل التوصية بالتسجيل.
[] **غير مناسبة الآن:** العميلة المحتملة تحتاج نوعا مختلفا من الدعم أو ليست جاهزة للمشاركة المطلوبة.

## الإكمال

يجب أن يكون عندك الآن:

- صورة مؤكدة عن الطريق الحالي للعميلة المحتملة
- الثمن العملي والشخصي المحدد لترك المشكلة من دون حل
- نتيجة مرغوبة مذكورة بوضوح
- قرار تناسب موثق
- شرح خاص بهذه العميلة المحتملة لكيف يعالج عرضك المشكلة
- قرار واضح أو خطوة تالية متفق عليها

استخدمي الخريطة المكتملة لتجهيز أول أولوية تطبيق للعميلة إذا اشترت. إذا لم تشتر، سجلي فقط القرار والخطوة التالية المتفق عليهما، ولا تحولي المحادثة إلى تعاقد استراتيجية غير مدفوع.
