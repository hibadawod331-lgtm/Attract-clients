## الهدف

ورقة العمل هذه تساعدك تقارنين بين تموضعات السلطة المعرفية الممكنة وتختارين الأوضح للبزنس تبعك. ستضيقين خبرتك إلى تركيبة واحدة قوية من الجمهور، والمشكلة، ووجهة النظر، والارتباط التجاري، حتى يفهم الناس المناسبون بسرعة لماذا شغلك مهم ومتى يطلبون مساعدتك.

هذه أداة قرار، وليست بايو نهائيا أو جملة تموضع نهائية. أنتِ تختارين الزاوية التي سيبنى حولها البراند والعرض في الخطوة التالية.

## التعليمات

خصصي 45 إلى 60 دقيقة لورقة العمل هذه. أكمليها خلال الجلسة إذا أمكن.

- اكتبي الخبرة، والتجربة، ومواضيع المحتوى التي تقدرين واقعيا أن تعرفي بها.
- اصنعي ثلاث زوايا سلطة ممكنة. اجعلي كل واحدة محددة بما يكفي لتوجه رسالتك، وواسعة بما يكفي لتدعم شغلا مدفوعا.
- استخدمي أسئلة الأدلة لتختبري هل كل زاوية مبنية على تجربتك الحقيقية ومشاكل جمهورك الفعلية.
- قيمي كل زاوية باستخدام مصفوفة القرار. لا تختاري فقط بناء على ما يبدو مثيرا أو مبهرا.
- اختاري زاوية سلطة أساسية واحدة. سجلي ما الذي تختارين عمدا ألا تبدئي به.
- استخدمي الزاوية المختارة لتوجيه قرارات التموضع والعرض التالية. لا تحوليها إلى جملة مصقولة بعد.

## 1. حددي سلطتك المعرفية القابلة للاستخدام

اكتبي المعرفة الموجودة عندك أصلا والتي تقدر تساعد نوعا محددا من الناس يعملون تغييرا ذا معنى.

| المجال | ملاحظاتك |
| مهارات أو خبرات تقدرين تعلمينها أو تطبقينها بثقة | |
| مشاكل حللتِها لنفسك | |
| مشاكل حللتِها لعميلات، أو زبونات، أو جمهور | |
| نتائج، أو تحسينات، أو قرارات دعمها شغلك | |
| أسئلة يسألك إياها الناس بشكل متكرر | |
| مواضيع محتوى تقدرين تشرحينها بعمق وبأمثلة حقيقية | |
| وجهة نظر، أو عملية، أو قناعة تجعل منهجك مختلفا | |
| شغل تريدين أن توظفي له أكثر | |

الآن أكملي هذه الجملة:

> أكثر جزء مفيد تجاريا من خبرتي هو مساعدة الناس _______________ لأن _______________.

إذا كان جوابك يشمل عدة مشاكل غير مرتبطة، ضعي دائرة حول المشكلة صاحبة أوضح رابط بالشغل المدفوع.

## 2. عرفي الأجزاء الأربعة لزاوية السلطة

زاوية السلطة مبنية من أربعة قرارات:

> **الجمهور + المشكلة + وجهة النظر + الارتباط التجاري**

### أ. الجمهور

اختاري المجموعة التي تفهمينها جيدا وتقدرين تخدمينها بفعالية.

تجنبي اختيار جمهور فقط لأنه كبير. اختاري ناسا عندهم وضع، أو حاجة، أو مرحلة بزنس يمكن التعرف عليها.

- من الأكثر احتمالا أن يستفيد من خبرتك؟
- ماذا يعرفون، أو يملكون، أو يعملون أصلا؟
- ما الذي يميزهم عن الجمهور العام؟
- من تفهمين جيدا بما يكفي لتتعرفي على إحباطاتهم وأولوياتهم الحقيقية؟

**الجمهور الممكن:**

> أريد أن أعرف عند _______________.

**وضعهم الحالي:**

> عندهم أصلا _______________، لكنهم يعانون في _______________.

### ب. المشكلة

اختاري المشكلة المحددة التي يريد جمهورك حلها، وليس موضوعا عاما تستمتعين بالكلام عنه.

المشكلة القوية غالبا تؤثر على واحد أو أكثر من هذه المجالات:

- الدخل أو جذب العميلات
- الوقت، أو الطاقة، أو تقديم الخدمة
- الثقة بالنفس أو اتخاذ القرار
- الظهور أو الثقة
- عملية متكررة لا تجلب النتيجة المقصودة

أكملي التالي:

> المشكلة الظاهرة عند الجمهور هي _______________.
>
> الثمن الأعمق على البزنس أو على المستوى الشخصي هو _______________.
>
> غالبا جربوا _______________، لكنه لم ينجح لأن _______________.
>
> الأرجح أنهم يطلبون المساعدة عندما _______________.

### ج. وجهة النظر

وجهة نظرك هي الطريقة التي تشرحين بها المشكلة والمبدأ الذي تستخدمينه لحلها. ليست شعارا. هي القناعة أو المنهج الذي يجعل طريقتك قابلة للتعرف عليها.

أكملي اثنتين على الأقل:

> معظم الناس يفترضون أن المشكلة هي _______________. أنا أؤمن أنها في الحقيقة _______________.
>
> الناس غالبا يحاولون _______________ أولا. أنا أجعلهم _______________ بدلا من ذلك.
>
> الخطأ الذي أساعد الناس يتوقفون عنه هو _______________.
>
> منهجي مختلف لأني _______________ بدل _______________.
>
> أول شيء أنظر إليه هو _______________ لأن _______________.

### د. الارتباط التجاري

زاوية سلطتك لازم تقود بشكل طبيعي إلى شغل يقدر أحد يدفع مقابله. هذا لا يتطلب إنهاء عرضك أو سعرك. يتطلب التأكد أن المشكلة مهمة بما يكفي ليطلب الجمهور دعما.

جاوبي على هذه الأسئلة:

- ما نوع المساعدة المدفوعة التي ممكن تقود إليها هذه الزاوية منطقيا؟
- مقابل ماذا ستدفع العميلة لتغيره، أو تحسنه، أو تحققه؟
- لماذا حل هذه المشكلة مهم الآن وليس في يوم ما؟
- هل المشكلة تتضمن ثمنا، أو خطرا، أو تأخيرا، أو فرصة ضائعة ذات معنى؟
- هل سيعرف الجمهور هذه كمشكلة يحتاجون مساعدة فيها، أم فقط كموضوع مثير؟

**اختبار الارتباط التجاري:**

> ممكن بشكل منطقي أن يوظفني أحد لأساعده _______________.
>
> حل هذه المشكلة مهم لأن _______________.
>
> أوضح لحظة سيبحثون فيها عن هذه المساعدة هي _______________.

## 3. ابني ثلاث زوايا سلطة ممكنة

اصنعي ثلاث تركيبات مختلفة. لا تصنعي ثلاث نسخ من نفس الفكرة المبهمة.

| | الزاوية أ | الزاوية ب | الزاوية ج |
| الجمهور المحدد | | | |
| المشكلة المباشرة | | | |
| الثمن أو النتيجة الأعمق | | | |
| وجهة نظري المميزة | | | |
| ما الذي ممكن أوظف لأساعد في تغييره | | | |
| لماذا يناسب هذا خبرتي الموجودة | | | |
| المحتوى أو الأدلة الموجودة عندي | | | |

استخدمي هذا الفحص قبل التقييم:

- هل كل زاوية تحدد جمهورا حقيقيا بدل «كل من يحتاج مساعدة»؟
- هل كل زاوية تسمي مشكلة بدل مجرد موضوع؟
- هل كل زاوية فيها وجهة نظر بدل قائمة مهارات؟
- هل كل زاوية مرتبطة بنتيجة مدفوعة من دون أن تصبح وصفا كاملا للعرض؟

اشطبي أي زاوية تفشل في فحصين أو أكثر.

## 4. اختبري كل زاوية مقابل أدلة حقيقية

استخدمي أدلة محددة، وليس تخمينات عما ممكن ينجح.

| سؤال الدليل | الزاوية أ | الزاوية ب | الزاوية ج |
| هل عملت هذا الشغل أو درسته بعمق شخصيا؟ ما الذي يثبت ذلك؟ | | | |
| هل سألني الناس عن هذه المشكلة من قبل؟ ماذا سألوا؟ | | | |
| هل عندي أمثلة، أو نتائج، أو آراء، أو تطبيقات عملية مرتبطة بها؟ | | | |
| هل أقدر أشرح المشكلة باللغة التي يستخدمها الجمهور أصلا؟ | | | |
| هل محتواي الموجود يدعم هذه الزاوية؟ أي مواضيع أو أمثلة؟ | | | |
| هل حل هذه المشكلة سيصنع تحسنا ذا معنى للجمهور؟ | | | |
| هل أقدر أستمر في المساعدة في هذه المشكلة من دون أن أحتاج أخترع بزنس جديد؟ | | | |

لكل زاوية، حددي مستوى الدليل:

- **قوي:** عندي تجربة مباشرة وأدلة واضحة.
- **ممكن:** عندي تجربة مرتبطة لكني أحتاج دليلا أو تحديدا أكثر.
- **ضعيف:** تعجبني الفكرة أساسا، لكني لا أقدر أدعمها بعد بتجربة، أو إشارات من الجمهور، أو أمثلة.

## 5. قيمي الخيارات

أعطي كل زاوية درجة من 1 إلى 5.

- **1:** ضعيفة جدا أو غير واضحة
- **3:** قابلة للاستخدام لكنها تحتاج تحسينا
- **5:** واضحة، ومحددة، ومدعومة بقوة

| عامل القرار | ماذا تبحثين عنه | الزاوية أ | الزاوية ب | الزاوية ج |
| وضوح الجمهور | مجموعة محددة تقدر تعرف أن الزاوية موجهة لها. | | | |
| إلحاح المشكلة | المشكلة تصنع ثمنا، أو إحباطا، أو تأخيرا، أو فرصة ضائعة ذات معنى. | | | |
| قوة وجهة النظر | الزاوية تعطيك طريقة قابلة للتعرف عليها لشرح المشكلة ومعالجتها. | | | |
| الأدلة والمصداقية | تجربتك، أو محتواك، أو نتائجك، أو شغلك مع العميلات يدعم الزاوية. | | | |
| الارتباط التجاري | المشكلة مرتبطة بشكل طبيعي بمساعدة مدفوعة ونتيجة ذات معنى. | | | |
| قابلية المحتوى | تقدرين تصنعين محتوى مفيدا من هذه الزاوية من دون تكرار نصائح عامة. | | | |
| القدرة على امتلاك المساحة | تقدرين تكونين مميزة من دون الحاجة للمنافسة على عدد المتابعين أو الشعبية العامة. | | | |
| الطاقة والالتزام | أنتِ مستعدة تستمرين مرتبطة بهذه المشكلة وهذا الجمهور. | | | |
| المجموع | اجمعي الدرجات. | | | |

### قواعد القرار

استخدمي هذه القواعد إلى جانب المجموع:

- لا تختاري زاوية درجة وضوح الجمهور فيها أقل من 3.
- لا تختاري زاوية درجة الارتباط التجاري فيها أقل من 3.
- إذا كانت زاويتان متقاربتين، اختاري صاحبة الأدلة الأقوى والمشكلة الأكثر إلحاحا.
- لا تختاري زاوية فقط لأنها تبدو أكثر إبهارا.
- لا توسعي الجمهور لتهربي من اتخاذ قرار واضح.
- لا تستخدمي «البراند الشخصي» أو «نمو البزنس» أو «العافية» أو أي موضوع عام آخر كمشكلة. سمي التغيير الذي يحتاجه الناس.

### الفحص النهائي للقرار

جاوبي بنعم أو لا:

| الفحص | نعم / لا |
| هل يقدر الجمهور المقصود يتعرف على نفسه في هذه الزاوية؟ | |
| هل تسمي مشكلة بدل مجرد موضوع؟ | |
| هل تعكس وجهة نظر أقدر أدافع عنها وأظهرها بثبات؟ | |
| هل عندي تجربة، أو محتوى، أو أدلة كافية لأبدأ من هنا؟ | |
| هل للمشكلة ارتباط تجاري واضح؟ | |
| هل تقدر هذه الزاوية توجه عرضي المستقبلي من دون أن أقرر العرض اليوم؟ | |
| هل اختيار هذه الزاوية سيجعل رسالتي أوضح من إبقاء عدة خيارات مفتوحة؟ | |

إذا كان أي جواب لا، عدلي الزاوية المختارة قبل أن تتقدمي. لا تحلي عدم اليقين بإضافة جماهير، أو مشاكل، أو خدمات أكثر.

## الإكمال

في نهاية ورقة العمل هذه، يجب أن يكون عندك:

- زاوية سلطة واحدة مختارة
- جمهور محدد بوضوح
- مشكلة محددة لها ثمن ذو معنى
- وجهة نظر مميزة عن سبب وجود المشكلة أو كيف تعالج
- رابط واضح بين المشكلة والدعم المدفوع
- قائمة قصيرة بالمواضيع أو الخبرات التي لن تبدئي بها الآن

أحضري الزاوية المختارة وأدلتك إلى الخطوة التالية. استخدميها لصنع جملة تموضع مختصرة، ثم شكلي عرضا حول المشكلة المحددة التي يتحمس جمهورك أصلا لحلها.
