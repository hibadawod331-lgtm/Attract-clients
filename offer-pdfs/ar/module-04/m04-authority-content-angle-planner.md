## الهدف

ورقة العمل هذه تساعدك تحولين تموضع السلطة الذي اخترتِه إلى مجموعة صغيرة من محاور المحتوى المتكررة التي يقدر جمهورك يتعرف عليها ويتذكرها. ستربطين كل محور بالمشكلة المحددة التي تحلينها، حتى يقوي محتواك تموضعك بدل أن يصبح مجموعة منشورات تعليمية غير مرتبطة.

في النهاية، سيكون عندك من ثلاث إلى خمس زوايا محتوى سلطة واضحة، وأسئلة عملية لصنع محتوى من كل واحدة.

## التعليمات

خصصي 45 إلى 60 دقيقة. أكملي ورقة العمل هذه باستخدام تموضع السلطة الذي اخترتِه في جلسة التموضع.

- اكتبي الجمهور، والمشكلة، ووجهة النظر، والنتيجة المرغوبة التي اخترتِها في «مرساة التموضع».
- قسمي المشكلة المحددة عند الجمهور إلى الطرق المختلفة التي تظهر بها في البزنس تبعهن أو في قراراتهن اليومية.
- حولي أنماط المشكلة هذه إلى زوايا محتوى متكررة باستخدام «باني الزوايا».
- اصنعي عدة أسئلة قابلة للتكرار تحت كل زاوية. هذه نقاط بداية، وليست منشورات جاهزة.
- قيمي كل زاوية واختاري من ثلاث إلى خمس زوايا محددة، ومفيدة، ومرتبطة بوضوح بتموضع سلطتك.
- استخدمي مجموعة الزوايا النهائية كدليلك المستمر لاختيار مواضيع المحتوى. لا تصنعي محور محتوى جديدا كل مرة تنشرين.

## 1. مرساة التموضع

استخدمي التموضع الذي اخترتِه أصلا في شغل السلطة. لا توسعيه ولا تستبدليه بنيش جديد هنا.

| عنصر التموضع | جوابك |
| الجمهور: من تساعدين؟ | |
| المشكلة المحددة: ماذا يعانين في حله؟ | |
| وجهة نظرك: بماذا تؤمنين عن هذه المشكلة ويشكل منهجك؟ | |
| منهجك أو اتجاه الحل: كيف تساعدينهن يتقدمن؟ | |
| النتيجة المرغوبة: ما التغيير ذو المعنى الذي يشتغلن نحوه؟ | |
| عبارة التعرف: بماذا يجب أن يفكر الناس عندما يشوفون محتواك؟ | |

## 3. ابني زوايا محتوى السلطة

اصنعي من أربع إلى ست زوايا ممكنة قبل أن تختاري مجموعتك النهائية.

الزاوية ليست موضوعا عاما مثل «التسويق» أو «الثقة بالنفس» أو «البزنس». هي عدسة محددة تقدرين تستخدمينها مرارا للكلام عن مشكلة جمهورك من موقع سلطتك.

استخدمي هذا الهيكل:

> أساعد [الجمهور] يفهمن أو يعالجن [جزءا محددا من المشكلة] عن طريق إظهار [وجهة نظري المميزة] لهن.

| اسم الزاوية | الجزء المحدد من المشكلة | ماذا يؤمن جمهورك أو يعمل حاليا | وجهة نظرك المميزة | ماذا تساعدهن هذه الزاوية يفهمن |
| 1. | | | | |
| 2. | | | | |
| 3. | | | | |
| 4. | | | | |
| 5. | | | | |
| 6. | | | | |

استخدمي الأسئلة التالية إذا احتجتِ مساعدة في تطوير الزوايا:

- ماذا يستمر جمهوري في عمله ويصنع المشكلة؟
- أي جزء من المشكلة يشرحه الآخرون بشكل عام جدا؟
- ماذا يحتجن أن يشوفن بترتيب مختلف؟
- أي تفريق سيساعدهن يتخذن قرارا أفضل؟
- أي سؤال أقدر أجاوب عليه مرارا من دون أن تنفد مني الأمثلة المفيدة؟
- ماذا يحتاج جمهوري أن يدرك قبل أن يكون جاهزا للتفكير في حلي؟
- أي جزء من خبرتي أقدر أشرحه من خلال مواقف كثيرة مختلفة؟
- ماذا سأتحدى، أو أبسط، أو أعيد صياغته لهذا الجمهور؟

## الإكمال

يجب أن يكون عندك الآن:

- مرساة تموضع ثابتة لمحتواك
- من ثلاث إلى خمس زوايا محتوى سلطة متكررة
- مشكلة جمهور واضحة مربوطة بكل زاوية
- وجهة نظر مميزة يقويها كل محور
- عدة أسئلة تقدرين تستخدمينها لصنع محتوى من دون أن تبدئي من صفحة فاضية

استخدمي مجموعة الزوايا النهائية لتختاري مواضيع المحتوى المستقبلية. كل محتوى جديد يجب أن يناسب زاوية واحدة على الأقل ويجعل جمهورك أكثر ميلا لربطك بالمشكلة المحددة التي تحلينها. خطوتك التالية أن تستخدمي هذه المحاور عند تطوير محتوى بناء الثقة ورسائل الجذب في المراحل اللاحقة من تسلسل تحويل العميلات.
