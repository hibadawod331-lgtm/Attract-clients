## الهدف

ورقة العمل هذه تساعدك تتعرفين متى أعطى أحد إشارة مرتبطة وتختارين دعوة خاصة تناسب اللحظة. ستحولين ردود الجمهور، وأسئلته، والمشاكل التي يذكرها إلى خطوات تالية طبيعية من دون بيع بارد، أو شرح زائد، أو إعطاء استراتيجية غير مدفوعة.

## التعليمات

خصصي 25 إلى 30 دقيقة.

- استخدمي إشارات حديثة من الجمهور من التعليقات، أو الردود على الستوري، أو الرسائل الخاصة، أو ردود الإيميل، أو المحادثات. اختاري إشارات مرتبطة بالمشكلة التي يحلها عرضك.
- سجلي كلمات الشخص الحرفية قدر الإمكان. لا تعيدي كتابة إشارته لتبدو أكثر إلحاحا مما كانت.
- صنفي كل إشارة حسب مستوى الاهتمام الذي تظهره.
- تأكدي هل الشخص مرتبط بجمهورك، ومشكلتك، وعرضك.
- اختاري أصغر دعوة خاصة مناسبة. الهدف فتح محادثة مرتبطة، وليس فرض مكالمة بيع.
- اكتبي الدعوة بأسلوبك. اجعليها قصيرة، ومحددة، وسهلة القبول أو الرفض.

## 2. صنفي إشارة الجمهور

استخدمي سطرا واحدا لكل إشارة حقيقية. سجلي كلمات الشخص بأكبر دقة ممكنة.

استخدمي مستويات الإشارة هذه:

### المستوى 1: فضول مرتبط

يتفاعلون مع موضوع مرتبط بشغلك لكن لم يذكروا مشكلة شخصية.

أمثلة:

- «هاد شي حلو.»
- «عمري ما فكرت فيها هيك.»
- رد يطلب توضيحا عن منهجك.

**الرد:** كملي المحادثة العامة أو اسألي سؤال توضيح خفيفا. لا تدعيهم فورا للشراء.

### المستوى 2: التعرف على المشكلة

يشيرون إلى أن المشكلة تنطبق عليهم.

أمثلة:

- «بنشر بانتظام، بس ما حدا بيسأل عن الشغل معي.»
- «عندي خبرة، بس لسا ما بقدر اشرح عرضي بوضوح.»
- «هاد بالزبط اللي عم عاني منه.»

**الرد:** اعترفي بالمشكلة واعرضي محادثة خاصة إذا كان هناك سبب واضح أنها ستساعد.

### المستوى 3: البحث الفعلي عن المساعدة

يسألون ماذا يعملون، أو كيف تساعدين، أو هل تشتغلين مع ناس في وضعهم.

أمثلة:

- «كيف بصلح هالشي؟»
- «بتساعدي الكوتشز بهالشي؟»
- «فينا نحكي عن وضعي؟»
- «كيف بيكون الشغل معك؟»

**الرد:** أعطي دعوة خاصة مباشرة مرتبطة بسؤالهم.

### المستوى 4: إشارة قرار أو جاهزية

يسألون عن الشغل مع بعض، أو التوقيت، أو المواعيد المتاحة، أو العملية، أو الخطوة التالية.

أمثلة:

- «كيف فيني اشتغل معك؟»
- «عم تاخدي عميلات؟»
- «شو الخطوة الجاية؟»
- «بفكر إني محتاجة مساعدة لركب هالشي.»

**الرد:** ادعيهم لخطوة التناسب أو طلب الانضمام المناسبة. لا تحتاجين تصنعين محتوى أكثر قبل الرد.

## 4. ابني الدعوة

استخدمي هذا الهيكل:

> **اعترفي بالإشارة ← اربطيها بسبب مرتبط ← اعرضي خطوة تالية خاصة ← أعطيها الخيار**

### معادلة الدعوة

> «منطقي. بما إنك ذكرتي [المشكلة أو الهدف المحدد]، فيني اسألك كم سؤال على الخاص لنشوف شو اللي عم يوقفك. بتحبي نكمل بالرسائل الخاصة؟»

**لإشارة بحث أقوى عن المساعدة:**

> «إي، هاد شي بساعد [الجمهور] يشتغلوا عليه. بناء على اللي شاركتيه عن [المشكلة المحددة]، ممكن يكون مفيد نطلع على وضعك مباشرة. بتحبي ابعتلك الخطوة الجاية؟»

**لإشارة جاهزية:**

> «شكلك جاهزة تشوفي كيف [النتيجة المرغوبة]. فيني ابعتلك تفاصيل محادثة التناسب لنشوف إذا العرض بيطابق اللي محتاجته. بتحبي؟»

### اصنعي بنك دعواتك

| المحفز أو الإشارة | الاعتراف | سبب مرتبط لنكمل على الخاص | الدعوة | الخيار أو الإذن |
| | | | | |
| | | | | |
| | | | | |
| | | | | |

قبل أن تعتمدي كل دعوة، تأكدي:

[] تشير إلى إشارة الشخص الفعلية.
[] لا تفترض أنها جاهزة للشراء.
[] لا تعد بنتيجة قبل فهم وضعها.
[] لا تشمل حلا كاملا أو جلسة استراتيجية غير مدفوعة.
[] تسمي خطوة تالية واحدة واضحة.
[] تسمح للشخص أن يقول نعم، أو لا، أو ليس بعد.
[] تبدو مثل شيء سأقوله بشكل طبيعي.

## الإكمال

في النهاية، يجب أن يكون عندك:

- تعريف واضح للمحادثة الخاصة التي تفتحينها
- من ثلاث إلى خمس إشارات حقيقية من الجمهور مرتبطة بمشكلة عرضك
- تفريق بين الفضول، والتعرف على المشكلة، والبحث عن المساعدة، والجاهزية
- خطوة تالية مناسبة لكل إشارة
- ثلاث قواعد دعوة مكتوبة ورسائل دعوة جاهزة للاستخدام

استخدمي هذه القواعد عند مراجعة الردود والأسئلة بعد نشر محتوى بناء الثقة. عندما يقبل أحد دعوة، انتقلي إلى عملية المحادثة الحقيقية وسجلي وضع الشخص، وتناسبه، وجاهزيته، والخطوة التالية المتفق عليها في «ورقة ملاحظات المحادثات الحقيقية».
