## الهدف

ورقة العمل هذه تساعدك تجهزين أجوبة واضحة ومباشرة على الأسئلة التي ممكن تسألها العميلة المحتملة بعد محادثة البيع. ستحددين لمن العرض، وكيف تبدو المشاركة، وكيف يشتغل التخصيص، ومتى يكون الدعم متاحا، وما الذي خارج الخدمة.

النتيجة بنك ردود جاهز للاستخدام يجعل العرض أسهل في الاختيار من دون شرح زائد، أو ارتجال، أو وعد بشغل لا يشمله العرض.

## التعليمات

خصصي 30 إلى 45 دقيقة. أبقي وصف عرضك النهائي، والسعر، وطريقة الدفع، والمخرجات قريبة منك.

- أكملي «مرساة العرض» أولا. استخدمي فقط تفاصيل قررتِها أصلا.
- اكتبي أجوبتك في بطاقات الردود الست. جاوبي على سؤال المشترية مباشرة قبل إضافة السياق.
- أكملي «بنك ردود الحدود» للطلبات التي ممكن توسع نطاق العرض.
- اقرئي كل جواب بصوت عال. احذفي الاعتذارات، والعبارات المبهمة، والاستراتيجية غير الضرورية، والوعود التي لا تقدرين تتحكمين فيها.
- احفظي الردود النهائية حيث تقدرين توصلين إليها خلال محادثات المتابعة.

استخدمي هيكل الرد هذا:

> **جواب مباشر ← شرح مختصر ← خطوة تالية واضحة**

مثال:

> «نعم، هذا مناسب إذا كان عندك أصلا خدمة أو مجال خبرة نبني حوله. سنحسن طريق العميلات ونركبه حول ما تعرفينه أصلا بدل صنع بزنس جديد بالكامل. إذا كان هذا يطابق وضعك، الخطوة التالية هي تأكيد تاريخ البداية.»

| 3. شغل التطبيق الأساسي | | |

## 4. بنك ردود الحدود

استخدمي هذا القسم عندما يكون الطلب ممكن يغير نطاق العرض، أو الوصول، أو الجدول الزمني، أو المسؤولية.

### معادلة الحدود

> **اعترفي بالهدف ← اذكري ما هو مشمول ← سمي ما هو خارج النطاق ← قدمي الخطوة التالية المناسبة**

مثال:

> «أفهم أنك تريدين مساعدة في هذا الإطلاق. هذا العرض يشمل تحسين طريق العميلات ورسائل البيع. لا يشمل إدارة الإطلاق أو إنتاج كل مواد الحملة. نقدر نقرر هل هذه المهمة مكانها في خطة التطبيق الخاصة بك أو تحتاج خدمة منفصلة.»

### جهزي ردودك

| طلب العميلة أو سؤالها | ما المشمول | ما خارج النطاق | ردك |
| «فيكي كمان _______________؟» | | | |
| «فيكي تعمليلي _______________؟» | | | |
| «فيني راسلك كل ما _______________؟» | | | |
| «فينا نمدد أو نغير _______________؟» | | | |
| «فيكي تضمنيلي _______________؟» | | | |
| «فيكي تراجعيلي كل _______________؟» | | | |
| «فينا نضيف _______________؟» | | | |

استخدمي بدايات الجمل هذه عند الحاجة:

- «هذا شغل منفصل عن _______________.»
- «ما هو مشمول هنا هو _______________.»
- «أقدر أوجهك في هذا خلال _______________.»
- «لا أقدم _______________ كجزء من هذا العرض.»
- «حتى يبقى الشغل مركزا على _______________، لن نضيف _______________.»
- «أقدر أجاوب على السؤال المحدد، لكن المراجعة الكاملة ستكون خارج النطاق الحالي.»
- «أقدر ألتزم بـ _______________. لا أقدر أعد بـ _______________.»
- «إذا كان هذا الدعم ضروريا، يجب أن نناقش هل _______________ هو الخدمة المناسبة.»

## 5. الفحص النهائي لبنك الردود

راجعي كل رد وحددي الجمل الصحيحة.

| الفحص | نعم / يحتاج تعديل |
| الجواب يبدأ برد مباشر بدل شرح طويل. | |
| الجواب يستخدم نفس اسم العرض، والمخرجات، والجدول الزمني، وقواعد الوصول الموجودة في مواد العرض. | |
| الجواب يوضح الأهلية من دون إهانة أو تجاهل العميلات المحتملات غير المناسبات. | |
| الجواب يشرح مسؤوليات العميلة. | |
| الجواب يفرق بين التخصيص والتغييرات غير المحدودة أو الشغل الإضافي. | |
| الجواب يذكر حدود الوصول بلغة بسيطة. | |
| الجواب لا يضمن عددا محددا من العميلات، أو المبيعات، أو الدخل. | |
| الجواب لا يعطي حلا استشاريا كاملا ردا على سؤال. | |
| الجواب ينتهي بخطوة تالية واضحة عندما تكون الخطوة التالية مناسبة. | |
| الجواب يبدو مثل شيء ستقولينه بشكل طبيعي في محادثة. | |

أعيدي كتابة أي رد يحتوي:

- «بيعتمد» من دون شرح على ماذا يعتمد
- «غالبا بقدر» عندما يجب أن يكون الجواب واضحا
- اعتذارا عن السعر، أو العملية، أو الحد
- وعدا بنتيجة لا تتحكمين فيها
- خدمات إضافية مضافة لتجنب خيبة أمل المشترية
- شرحا طويلا يجاوب على أسئلة لم تسألها المشترية

## الإكمال

يجب أن يكون عندك الآن بنك ردود مختصر يغطي:

- من المناسب ومن غير المناسب
- ماذا تحتاج العميلة قبل أن تبدأ
- ماذا يحدث بعد التسجيل
- كيف يقدم الشغل
- ما الوصول المتاح بين الجلسات
- كيف يخصص الشغل
- كيف يدار التوقيت والتقدم
- أي طلبات خارج حدود الخدمة

استخدمي هذه الردود في المتابعة، ومحادثات التسجيل، واستقبال العميلات الجدد. أبقي البنك بجانب مواد عرضك وحدثيه فقط عندما تغيرين العرض، أو تقديمه، أو حدوده عن قصد.
